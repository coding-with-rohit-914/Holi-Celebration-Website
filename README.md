### Happy Holi 2024 Celebration Website


-- A vibrant, full-screen video background website celebrating the Holi festival with immersive visuals and a responsive design.

# Demo: https://happy-holi-bash.netlify.app/

🎨 Features

-- Full-Screen Video Background: Plays an immersive Happy Holi celebration video automatically
-- Responsive Design: Adapts to different screen sizes with Bootstrap integration
-- Minimalist Interface: Clean design that puts the festive visuals front and center
-- Auto-Playing Video: Background video loops seamlessly with muted audio
-- Dark Theme: Black background that enhances video contrast

🛠️ Technologies Used

-- HTML5: Semantic structure with video element
-- CSS3: Custom styling with animations and responsive design
-- Bootstrap 4.4.1: Responsive grid system and components
-- Poppins Font: Modern, readable typography
-- MP4 Video: Full-screen celebratory background content

🎥 Video Implementation

-- Auto-play: Video starts automatically on page load
-- Looping: Continuous playback for immersive experience
-- Muted: Automatic audio muting for better user experience
-- Responsive: Video scales to fit all screen sizes
-- Background: Positioned as full-screen backdrop

📱 Design Elements

-- Full Immersion: Video covers entire viewport
-- Minimal Navigation: Clean interface (navigation commented out but available)
-- Color Scheme: Black background with vibrant video colors
-- Typography: Modern Poppins font for any text elements

🚀 How to Use

-- Open the website to immediately experience the Holi celebration video
-- The video plays automatically in full-screen background mode
-- No interaction needed - just enjoy the festive visuals
-- Responsive on all devices - works on desktop, tablet, and mobile
